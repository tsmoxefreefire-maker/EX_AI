# 🎓 الشرح التفاعلي (Interactive Explanation)

صفحة بتشرح كل درس بـ**مشاهد متحركة وتفاعلية** (SVG): الطالب بيشوف، بيحرّك، وبيجرّب. كل إشي فيها جاي من **جراف المنهج** (المفاهيم + مين بيحتاج مين). **بلا AI بالأساس**، فالتكلفة تقريباً صفر.

- **🆕 كله بيشتغل من FastAPI:** ابعت **أي جراف** ← السيرفر بيعمل الشرح كامل وبيعطيك **الصفحة نفسها** (`/explain`) بكل التفاعلات والأصوات، والداتا JSON لأي فرونت إند.
- **🆕 المادة الجديدة كلياً بتاخد هوية خاصة فيها:** صوت خاص، شخصيات بشكلها ولون لكل مفهوم، والاسم كامل، وشخصية بتسلّم باسمها.
- **١٢ كتاب تجريبي** من الصف الرابع للثاني عشر · **٦٢٢ مشهد** · **٤ مراحل عمرية** · **١٩ نوع مشهد**.
- **الناقص:** `MISSING_AR.md` · **لو ضفنا دروس أو مواد جديدة:** `NEW_CONTENT_AR.md` · **تاريخ كل تعديل مع الكود:** `02_question_factory/CHANGES_AR.md` · **شرح الـ API ملف ملف:** `05_explanation_api/EXPLANATION_API_AR.md`.
- **🆕 💡 مستكشف الكود «زي PyCharm» (فكرة حارث):** افتح `code_tour/PROJECT_EXPLORER.html` بالمتصفح: كل ملفات المشروع عاليسار، الكود الحقيقي بالنص، وشرح كل ملف وكل فانكشن بالعربي عاليمين (على شو بيعتمد ومين بيستعمله)، و«🔢 خطوة خطوة» بترتيب الشغل. بعد أي تعديل: `python code_tour/build_project_explorer.py`.
- **🆕 💡 رحلة الكود (فكرة حارث):** افتح `code_tour/CODE_TOUR.html` بالمتصفح: ٤١ خطوة مرقّمة من لما الجراف يوصل للسيرفر لحد ما المتصفح يرسم، كل خطوة فيها شرحها بالعربي وكودها الحقيقي بأرقام سطوره.

## ٠. ▶️ التشغيل (FastAPI)
```bash
cd 05_explanation_api
pip install -r requirements.txt
uvicorn main:app --reload
```
| افتح | شو بتلاقي |
|---|---|
| `http://127.0.0.1:8000/` | **صفحة السيرفر:** الكتب + **«➕ جراف جديد»** (اسحب ملف JSON ← «ولّد الشرح» ← «افتح الشرح») |
| `/explain` · `/explain/{book_id}` | **الصفحة التفاعلية** (كل الكتب · كتاب واحد) |
| `/docs` | كل الطلبات، وبتقدر تجرّبها من المتصفح |

**أول مرة** السيرفر بيشتغل وما في كتب، **بيعمل الكتب الـ١٢ لحاله** (ربع ثانية تقريباً). وللصفحة المبنية بدون سيرفر: `02_question_factory/player/explain.html` (نفسها بالبايت).

### من كود (أي فرونت إند)
```bash
curl -X POST http://127.0.0.1:8000/explanations/generate -H "Content-Type: application/json" \
     -d "{\"graph\": $(cat 02_question_factory/examples/new_subject_computer_g7.json)}"
# ← {"book_id": "cs_g7", "scenes": 54, "identity": {"family": "computer", "emblem": "💻", "sound": {"instr": "chip", …}}, "page_url": "/explain/cs_g7", …}
```
| الطلب | شو بيعمل |
|---|---|
| `POST /explanations/generate` | جراف ← شرح كل الدروس (بينحفظ) ← `page_url` |
| `GET /explain` · `/explain/{id}` · `/explain-data` | الصفحة · صفحة كتاب · **نفس داتا الصفحة** JSON |
| `GET /books` · `DELETE /books/{id}` · `POST /explanations/samples` | الكتب · احذف كتاب · اعمل الكتب الـ١٢ |
| `GET /lessons/{id}/explanation` · `/concepts/{id}/explanation` | مشاهد درس · مفهوم |
| `GET /art/{key}.svg?stage=kids` | رسمة الشخصية (وجهها حسب العمر) |
| `GET /scene-kinds` · `/llm/…` | العقد (كل نوع مشهد وحقوله) · مشاهد الموديل |

## ١. كيف بيشتغل (من الجراف للصفحة)
```
الجراف (JSON)                       ← المفاهيم، معانيها، والأسهم «بيحتاج»
   │
   ▼  المصنع (بايثون، 02_question_factory)
explain_generator.py + explain_activities.py + audience.py
   │   لكل درس ← لكل مفهوم ← مشاهد · كل مشهد بيتفحص مع الجراف (check_scene)
   ▼
explanations.json لكل درس           ← الكلام جاهز حسب عمر الطالب
   │
   ▼  build_explain_player.py  +  كود الصفحة (03_explain_player_src)
explain.html                        ← صفحة وحدة فيها كل إشي
```
- **قاعدة الصدق:** أي جملة «س بيحتاج ص» لازم يكون إلها سهم بالجراف. والمشهد اللي فيه غلط **ما بيوصل للطالب** (`explain_main.py` بيشيله).
- **العمر:** صف الكتاب ← المرحلة (`audience.py`) ← طريقة الحكي. ونفس القواعد بالصفحة (`stage.js`).
- **الـ API** (FastAPI، `05_explanation_api`) بيستعمل **نفس المصنع ونفس باني الصفحة** مباشرة (ما في نسخة ثانية)، فالصفحة من السيرفر = الصفحة المبنية.

## ٤. المراحل العمرية (من صف الكتاب)
| المرحلة | الشخصيات | الكلام | الأصوات |
|---|---|---|---|
| 🌈 الصغار (١–٤) | وجه كامل وضحك | زي ما هو | ألحان صغيرة · الفارة: ضحكة بصوت الشخصية |
| 🧭 ابتدائي عليا (٥–٧) | بلا خدود ولا ضحك | إيموجي أقل | ناعمة · الفارة: «همم؟» |
| 🔬 إعدادي (٨–٩) | عيون بس | «بيعتمد على» بدل «بيحتاج» | نوتات قصيرة · الفارة: 🆕 نوتتين طالعات + اسم ومعنى |
| 📐 ثانوي (١٠–١٢) | بلا وجوه | بلا إيموجي، «نقاش»، «التعريف» | 🆕 أعمق وأهدى (أوكتاف أوطى) · الفارة: نوتة دافية + اسم ومعنى |

بالصفحة في مفتاح **«👥 المرحلة»**: 🆕 بياخدك **لكتب هالمرحلة** (والقائمة مقسومة بالمراحل)، وزر **«🎵 اسمع»** لعيّنة من أصواتها.

## ٥. الأصوات (`sound.js`)
- **المادة بتقرر الآلة:** علوم ماريمبا · رياضيات وتر · فيزياء بيانو كهربائي · كيمياء زجاج · جغرافيا كاليمبا · تاريخ خشب · لغة ناي. 🆕 **والمادة الجديدة صوتها من هويتها** (فوق).
- **بلا تكرار:** النوتة من سلّم المادة، وغير اللي قبلها. والصح ورا الصح بيطلع لفوق.
- **صوت بس لما الطالب يعمل إشي** (يكبس، يسحب، يجاوب، يخلّص)، و«القراءة بصوت عالي» انشالت.
- 🆕 **موسيقى المرحلة بتشتغل لحالها** لما توصل لمرحلة (تختارها، أو تفتح كتاب من مرحلة ثانية، أو تفتح الصفحة: بعد أول لمسة، قانون المتصفح). نفس المرحلة ← ما بتنعاد. «🎵 اسمع» بيعيدها.

```bash
cd 03_explain_player_src && python build_explain_template.py      # كود الصفحة ← القالب
```

**المفاتيح:** بمتغيرات البيئة (`GEMINI_API_KEY` / `OPENAI_API_KEY`). **لا ترفع أي مفتاح على GitHub.**

## ٨. قواعد لما تعدّل (تعلّمناها من أغلاط صارت)
- **أي class جديد اسمه خاص** (`na-…`، `hv-…`)، لأنه في أسماء مكررة بالصفحة (`.face` `.tail` `.lifted`).
- **ولا حركة CSS على `<g>` إله `transform`** (حرّك المجموعة اللي جوا).
- **ولا زر جوا زر.**
- **الحركات بالوقت** (`performance.now()`)، مش بعدد الإطارات.
- **كل كلام بيمر من `VOICE` / `richText`** (عشان العمر).
- **الطالب هو اللي بيعمل**، والفيديو بيشغّل الكلام بس.
- **بعد أي تعديل:** ابني وشغّل الفحوصات، ولازم يطلع ٠ مشاكل.
